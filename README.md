# 🕹️ Yroom - 千禧赛博房间 (The Millennium Cyber Room)

> *"00 是年代，Y 是 Y2K，是 Youth（青春），是 Yesterday（昨天），是 You（你），也是打的一个 Yawn（哈欠）。"*

这是一个纯前端手搓的复古终端项目。
目前项目**未完工（主界面还在建模中）**，但核心的独立设备已经全部竣工！

### 🚧 施工进度
- [x] 绿屏 MP3 (绿底点阵屏 / 纯物理按键 / 音频降质滤镜)
- [x] 黑胶唱片机 (幻觉飞盘动画 / 黑胶爆豆底噪 / CD/LP切换)
- [x] 赛博电视机 (雪花屏 / CRT扫描线 / 黑白/彩色滤镜)
- [ ] Yroom 主界面大厅 (开发中...)
